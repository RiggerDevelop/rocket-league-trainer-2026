## 🧩 About

**Rocket League Trainer** is a collection of Rocket League open-source tools:

- **Mod Menu** — wall vision, boost radar, overlay profiles
- **Item Swapper** — swap item appearances (terminal + GUI)
- **AI Bot** — RLGym + PPO training framework
- **Replay Parser** — parse and generate `.replay` files
- **BakkesMod SDK** — plugin development framework

---

## ✨ Features

### 🎯 Mod Menu
- Wall vision, boost pad radar
- Configurable profiles
- Low-signature injection

### 💎 Item Swapper
- Swap item appearances (Standard Boost → Alpha Reward)
- Auto-backup and restore
- Terminal + GUI

### 🤖 AI Bot Framework
- RLGym + PPO training
- 116-feature observation space
- 19 discrete actions

### 🎮 Replay Tools
- Parse `.replay` to JSON
- Generate `.replay` from JSON
- Minify JSON output

### 🛠️ BakkesMod
- Official SDK for plugin development
- Custom training plugins

**Is this detectable?**

**What is BakkesMod?**
A popular Rocket League training framework. SDK available on GitHub.

**What is RLGym?**
A Python environment for training RL bots without playing the actual game.
